Los tipos de datos primitivos son las categorías básicas en las que se pueden clasificar los datos en programación. Estos tipos incluyen booleanos, enteros, flotantes y cadenas de texto. Las variables son contenedores que almacenan estos datos y su tipo determina cómo se pueden manipular. La función describir_tipo permite identificar el tipo de dato de una variable específica. Esta función utiliza la instrucción isinstance para verificar si el valor proporcionado es de un tipo particular, como bool, int, float o str, y devuelve una cadena que indica el tipo correspondiente. Por ejemplo, si se llama a describir_tipo con el valor verdadero, la función devolverá "bool", indicando que el tipo de dato es booleano.
