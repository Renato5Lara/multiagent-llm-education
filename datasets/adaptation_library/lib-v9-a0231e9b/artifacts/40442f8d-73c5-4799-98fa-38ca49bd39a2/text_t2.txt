Los bucles son estructuras de control que permiten repetir un bloque de código varias veces. En el flujo de los bucles, las instrucciones break y continue juegan un papel importante. La instrucción break se utiliza para salir del bucle de manera anticipada, mientras que continue permite saltar a la siguiente iteración del bucle sin ejecutar el resto del código en la iteración actual. Veamos cómo funcionan estas instrucciones en el contexto de las funciones primer_multiplo_de_tres y detener_en_negativo. En primer_multiplo_de_tres, se recibe una lista de números y se itera sobre cada uno. Si un número no es múltiplo de tres, se utiliza continue para saltar a la siguiente iteración. Si se encuentra un número que sí es múltiplo de tres, se devuelve inmediatamente. Por ejemplo, si la lista es uno, dos, tres, cuatro, cinco, el flujo del bucle saltará los números uno y dos, y devolverá tres. Si no hay múltiplos de tres, se devuelve None. En la función detener_en_negativo, se construye una lista de resultados a partir de los números que se reciben. Si se encuentra un número negativo, se utiliza break para salir del bucle. Por ejemplo, si la lista es cinco, tres, uno, menos dos, el flujo del bucle añadirá cinco, tres y uno a la lista de resultados, pero al encontrar menos dos, se detendrá. Un error común que conviene evitar es no entender cómo break y continue afectan el flujo del bucle, lo que puede llevar a resultados inesperados o a bucles infinitos.
