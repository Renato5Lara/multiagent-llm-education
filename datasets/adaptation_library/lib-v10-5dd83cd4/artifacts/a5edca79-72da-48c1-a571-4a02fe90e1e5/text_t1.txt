La salida básica en programación se refiere a la forma en que un programa muestra información al usuario. Una de las funciones más comunes para realizar esta tarea es la función print. En el código de referencia, se define la función formatear_reporte, que toma dos parámetros: nombre y nota. Dentro de esta función, se crea una línea de texto que combina el nombre del estudiante con su nota utilizando una cadena formateada. Luego, esta línea se muestra en la salida utilizando la función print. Por ejemplo, si llamamos a formatear_reporte con el nombre "Juan" y la nota "Ninety", la salida será "Estudiante: Juan - Nota: Ninety". Esto ilustra cómo se puede utilizar la salida básica para comunicar información de manera clara y efectiva en un programa.
