La búsqueda en arreglos permite encontrar la posición de un elemento específico dentro de una lista. En el código de referencia, la función buscar_estudiante utiliza la expresión "nombre in lista" para verificar si el nombre está presente y, si es así, utiliza la función ".index()" para devolver su posición. Si el nombre no se encuentra, la función retorna -1, indicando que no se realizó la búsqueda con éxito.
