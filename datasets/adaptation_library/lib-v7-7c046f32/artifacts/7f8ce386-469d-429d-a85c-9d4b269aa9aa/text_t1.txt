La búsqueda en arreglos es una técnica fundamental que permite encontrar elementos específicos dentro de una lista. En el código proporcionado, la función buscar_estudiante recibe dos parámetros: una lista de estudiantes y un nombre que se desea buscar. Primero, verifica si el nombre está presente en la lista utilizando la expresión "nombre in lista". Si el nombre se encuentra, la función utiliza "lista.index(nombre)" para devolver la posición del nombre dentro de la lista. Si el nombre no está presente, la función retorna -1, indicando que no se encontró el elemento. Por ejemplo, si tenemos una lista de estudiantes que incluye a "Juan", "María" y "Pedro", y llamamos a buscar_estudiante con el nombre "María", la función devolverá el índice correspondiente a "María" en la lista.
