La conversión de tipos es el proceso mediante el cual se transforma una variable de un tipo de dato a otro. En programación, es común que necesitemos convertir datos para realizar operaciones adecuadas. Por ejemplo, en el código que se presenta, la función convertir_a_numero toma un texto como entrada y verifica si contiene un punto. Si es así, convierte el texto a un número de tipo flotante, es decir, un número decimal. Si no hay un punto, convierte el texto a un número entero. Esto permite que podamos trabajar con datos numéricos en lugar de cadenas de texto. Por ejemplo, si se pasa el texto "3.14", la función devolverá el número 3.14 como un flotante, mientras que si se pasa "5", devolverá el número 5 como un entero.
