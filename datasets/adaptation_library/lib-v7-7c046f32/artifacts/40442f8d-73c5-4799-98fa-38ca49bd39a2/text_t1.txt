El flujo de bucles en programación se refiere a la manera en que se ejecutan las instrucciones dentro de un bucle, y las palabras clave break y continue son herramientas que permiten controlar este flujo. La función primer_multiplo_de_tres recibe una lista de números y utiliza un bucle para iterar sobre ellos. Si un número no es múltiplo de tres, la instrucción continue hace que el bucle salte a la siguiente iteración, ignorando el número actual. Si encuentra un número que sí es múltiplo de tres, lo devuelve y termina la función. Si no encuentra ninguno, devuelve None. Por otro lado, la función detener_en_negativo también utiliza un bucle, pero en este caso, si encuentra un número negativo, la instrucción break interrumpe el bucle y se detiene la ejecución, devolviendo una lista con los números positivos que se encontraron antes del negativo. Por ejemplo, si se pasa la lista [1, 2, 3, -1, 4] a detener_en_negativo, el resultado será [1, 2, 3].
