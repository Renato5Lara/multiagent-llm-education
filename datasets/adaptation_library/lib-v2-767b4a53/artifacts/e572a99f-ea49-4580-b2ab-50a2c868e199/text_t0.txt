Los bucles anidados son estructuras de control que permiten ejecutar un bucle dentro de otro, facilitando la iteración sobre múltiples dimensiones de datos. En el código de la función tabla_multiplicar, se utilizan bucles anidados para generar una tabla de multiplicar, donde el bucle externo recorre las filas y el bucle interno calcula los productos para cada fila. Esto permite crear una lista de listas que representa la tabla de multiplicar de un número dado.
