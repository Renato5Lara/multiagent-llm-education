Los bucles son estructuras de control que permiten repetir un bloque de código varias veces. En el flujo de los bucles, las instrucciones break y continue juegan un papel fundamental. La instrucción break se utiliza para salir de un bucle de manera anticipada, mientras que continue permite saltar a la siguiente iteración del bucle sin ejecutar el resto del código en la iteración actual. Veamos cómo funcionan estas instrucciones en el contexto de las funciones primer_multiplo_de_tres y detener_en_negativo. En primer_multiplo_de_tres, se recibe una lista de números. El bucle for recorre cada número y verifica si es múltiplo de tres. Si no lo es, se utiliza continue para saltar a la siguiente iteración. Si encuentra un número que sí es múltiplo de tres, lo devuelve. Por ejemplo, si la lista es uno, dos, tres, cuatro, cinco, el flujo del bucle ignorará uno y dos, y devolverá tres. Si no hay múltiplos de tres, la función devolverá None. En la función detener_en_negativo, el bucle también recorre una lista de números, pero aquí se utiliza break. Si encuentra un número negativo, el bucle se detiene y no se añaden más números a la lista de resultados. Por ejemplo, si la lista es cinco, tres, uno, menos uno, el bucle se detendrá al encontrar menos uno. Un error común que conviene evitar es no entender cómo break y continue afectan el flujo del bucle, lo que puede llevar a resultados inesperados o a bucles infinitos si no se manejan correctamente.
