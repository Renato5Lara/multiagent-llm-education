La entrada básica en programación se refiere a la capacidad de recibir datos del usuario, y en Python, esto se logra a través de la función input. Esta función permite que el programa pause su ejecución y espere a que el usuario ingrese información. En el contexto del código de referencia, la función leer_edad toma un argumento llamado texto_ingresado, que simula lo que la función input devolvería como un string. Dentro de la función, se convierte ese string a un número entero utilizando la función int, lo que permite almacenar la edad como una variable de tipo entero. Por ejemplo, si el usuario ingresa "25", la función leer_edad convertirá ese texto en el número 25 y lo devolverá. Esto ilustra cómo se pueden manejar variables y tipos de datos en programación, facilitando la interacción con el usuario.
